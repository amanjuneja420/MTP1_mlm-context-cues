# Context and Domain Cues in Masked-Word Prediction

Code and results for the Masters Thesis Project (MTP-1) *Context and Domain Cues in Masked-Word
Prediction: An Interpretability Study of BERT and RoBERTa*, Department of Artificial
Intelligence, IIT Kharagpur, 2026.

**Author:** Aman Juneja  **Supervisor:** Prof. Koustav Rudra

## The question

Given *"The patient is taking [MASK] since the last 2 years."*, vanilla BERT and RoBERTa
(no fine-tuning) fill the blank with medical words. When *patient* is replaced by the neutral
word *person*, they still prefer *drugs* and *medication*. The project asks:

1. **Which context words drive the prediction**, and how should a word's influence be measured?
2. **Where in the network is the prediction formed?**
3. **Is the behaviour general** across BERT/RoBERTa, base/large, and a 500-sentence,
   10-domain collection?
4. **Why does it happen:** the masked-LM architecture, or the training text?

## Repository layout

```
data/          sentences.csv                   500 sentences, 10 domains x 50, one masked target each
experiments/   scripts that run the models and write raw results
analysis/      scripts that turn raw results into the tables and figures of the report
results/       all raw outputs and derived tables, exactly as used in the report
figures/       the data figures of the report (regenerated by analysis/make_figures.py)
```

## Models

All models are used as released on the Hugging Face Hub, without fine-tuning.

| Role | Models |
|---|---|
| Main subjects | `bert-base-uncased`, `bert-large-uncased`, `roberta-base`, `roberta-large` |
| Domain-adapted controls | `microsoft/BiomedNLP-BiomedBERT-base-uncased-abstract-fulltext`, `emilyalsentzer/Bio_ClinicalBERT`, `nlpaueb/legal-bert-base-uncased` |
| Exploratory (not in the MTP-1 report) | `gpt2`, `gpt2-medium` |

## Experiments

Output files keep the prefix of the experiment that wrote them (`c1_…`, `x1_…`, `e7_…`).

### Case study: the patient/person sentence (BERT-base) → `results/case_study/`

| Script | What it does | Report |
|---|---|---|
| `c0_reference_snippet.py` | Reference top-10 snippet (roberta-base), kept verbatim | Ch. 5.1 |
| `c0b_observe_case_sentences.py` | Same snippet on the patient/person sentences | Ch. 5.1 |
| `c1_topk_baseline.py` | Final-layer top-10 over domain frames, subject sweep and verb sweep | Ch. 5.2 |
| `c2_minimal_pairs.py` | Change one element at a time (subject, verb, masked slot, time phrase, negation) | Ch. 5.2, 5.5 |
| `c3_logit_lens.py` | Logit lens: the MLM head applied to every layer at the mask | Ch. 5.6 |
| `c4_attention_at_mask.py` | Attention from the mask, per layer and head | exploratory, not used in the report |
| `c5_occlusion.py` | Replace each context word with [MASK], measure KL at the target | Ch. 5.4 (the earlier mask-based analysis whose limitation is measured in Ch. 8.1) |
| `c6_layerwise_occlusion.py` | Logit lens under occlusion | exploratory, superseded by C8 |
| `c7_subject_ladder.py` | Remove the subject step by step: is *medication* selected or a default? | Ch. 5.3 |
| `c8_activation_patching.py` | Activation patching (clean → corrupted) at every layer and position | Ch. 5.7 |

The `c8_patching_occlude_*_COMPARISON` files use a [MASK]-corrupted run. They are kept for comparison
only: at early layers, patching into a masked position injects content the run never had,
so they are not read causally. The counterfactual runs (`patient_to_athlete`,
`patient_to_machine`, `taking_to_eating`) are the ones used in the report.

### Replication of Aoyama & Schneider (2022) → `results/case_study/a1_*`

`a1_aoyama_replication.py` implements probe-less probing (layer-wise word and POS match,
expected layer). `--demo` runs the paper's own example sentence; on it, the layer-12 top-10
matches the paper's Table 2 token for token (Ch. 7.2, validation). Without `--demo` it runs a
10-sentence pilot on the collection. The four-model version used in the report is part
`aoyama` of `x2_extended.py`.

### 500 sentences across four models → `results/x1_crossmodel/`

`x1_crossmodel.py`

| Part | What it does | Report |
|---|---|---|
| A | Target rank and probability, top-10, and the logit-lens readout at every layer | Ch. 6.1, 7.1 |
| B | Context attribution: each word removed by **deleting** it and by **masking** it | Ch. 8.1 |
| C | Grid of 15 subjects × 10 time expressions for *"The ___ is taking [MASK] …"* | Ch. 5.4 |

### Extended experiments → `results/x2_extended/`

`x2_extended.py`, one part per paper from the project reading list:

| Part | Id | What it does | Report |
|---|---|---|---|
| `domain` | E1 | Parts A and C of `x1_crossmodel.py` for the three domain-adapted BERTs | Ch. 8.2 |
| `ar` | E2 | GPT-2 / GPT-2-medium candidate scoring as a left-to-right control | **not in the MTP-1 report**; exploratory, planned for MTP-2 |
| `aoyama` | E3 | Probe-less probing on 100 sentences, four models | Ch. 7.2 |
| `attn` | E4 | Where the mask attends per layer ([CLS], [SEP], self, neighbours, punctuation) | Ch. 7.3 |
| `conf` | E5 | Saves each model's sorted output distribution for conformal prediction | Ch. 6.4 |
| `multi` | E6 | Multi-token targets: k masks, three decoding orders | Ch. 6.5 |
| `patch` | E7 | Activation patching on all four models (subject, duration, verb corruptions) | Ch. 5.7 |
| `grid2` | E8 | Verb frames (tense, aspect, negation, other verbs) × subjects × time expressions | Ch. 5.5 |

The `e5_dist_<model>.npz` files (about 9 MB each) store, for each of the 500 sentences, the
model's top-5000 output probabilities in sorted order, the probability of the correct
word, its domain, and whether it is a single token. The conformal prediction sets are
computed from these in `analyze_x2.py`, so they can be checked without re-running the models.

## Reproducing

Python 3.12 or newer. Results were produced on CPU with `torch 2.13.0` and `transformers 5.14.1`.

```bash
pip install -r requirements.txt

# models (CPU timings from the original runs)
python experiments/c1_topk_baseline.py            # likewise c0, c0b, c2-c8 (each takes seconds to minutes)
python experiments/a1_aoyama_replication.py --demo
python experiments/x1_crossmodel.py                # about 45 min for all four models
python experiments/x2_extended.py                  # about 1.5 h for all parts

# tables and figures
python analysis/analyze_x1.py results/x1_crossmodel results/x1_crossmodel/analysis
python analysis/semantic_domains.py results/x1_crossmodel results/x1_crossmodel/analysis
python analysis/frequency.py results/x1_crossmodel results/x1_crossmodel/analysis
python analysis/analyze_x2.py results/x2_extended results/x1_crossmodel results/x2_extended/analysis
python analysis/make_figures.py
```

Scripts skip outputs that already exist; pass `--force` to `x1_crossmodel.py` or
`x2_extended.py` to recompute. `--limit N` runs N sentences per domain as a quick test.
Running the analysis scripts on the included results reproduces the report's tables.

## Notes

- Forward passes are deterministic, so there are no seeds to vary. The only random step is
  the calibration/test split for conformal prediction, which uses a fixed seed.
- Attention weights require `attn_implementation="eager"` in recent `transformers`
  versions; the scripts set it.
- The logit lens is unreliable in early layers (most visibly in the 24-layer models), so
  early-layer readouts are not interpreted on their own; activation patching is used for
  causal claims.
